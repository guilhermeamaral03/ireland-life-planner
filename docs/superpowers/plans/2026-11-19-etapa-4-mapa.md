# Etapa 4 — Mapa de Cork: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mapa interativo do County Cork com localidades editáveis, ficha completa, distância em linha reta, rota de carro (OSRM), link de transporte público, favoritos e filtros.

**Architecture:** Domínio puro (`src/domain/geo.ts`, `src/domain/locations.ts`), cliente OSRM isolado (`src/services/osrm.ts`, fetch injetável para teste), seed de localidades em `src/data/seed/locations.ts`, página `/mapa` com `react-leaflet`.

**Tech Stack:** existentes + `leaflet`, `react-leaflet`, `@types/leaflet`.

**Spec:** `docs/superpowers/specs/2026-11-19-ireland-life-planner-design.md` — seções 7 e **15**.

## Global Constraints

- Nenhum texto descritivo, aluguel, tempo ou indicador inventado; vazio → "Não disponível".
- Linha reta sempre rotulada "em linha reta"; carro sempre "estimativa sem trânsito — OSRM" + data da consulta; tempo de transporte só com status e fonte informados pelo usuário.
- Requisições externas só com coordenadas (OSRM, tiles). Atribuição "© OpenStreetMap contributors" visível.
- Marcadores com `CircleMarker` (evita problema de ícones do Leaflet no Vite).
- 375 px sem rolagem lateral; ficha abaixo do mapa no celular.

## Review Focus

1. OSRM fora do ar / offline / resposta sem rota → "Não disponível" + botão "Tentar de novo", sem travar a ficha.
2. Excluir Cork City → bloqueado com mensagem; excluir outra localidade → some do mapa e da lista.
3. Recarregar não duplica as localidades iniciais; apagar todos os dados (Configurações) volta a semeá-las.
4. Mover/editar coordenadas inválidas (lat fora de −90..90, lng fora de −180..180) → recusado.
5. Backup feito antes desta etapa (sem a flag de seed) → importação não duplica nem perde localidades.
